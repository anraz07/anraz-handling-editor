# qb-vehicle-handling-editor

**Version:** 1.0.0
**Framework:** QBCORE
**Category:** Vehicle
**Created:** 11/06/2026

## Description

Script para modificar handling de vehiculos en QBCore. El script se puede usar con el comando que abre un menu interactivo para poder ajustar y guardar el handling.

## Features

-Edición de parametros de handling de coches
-Uso en caliente
-Posibilidad de resetear valores a predeterminados
-Export del handling del vehiculo seleccionado

## Requirements

- FiveM Server (Server 5848+)
- QBCORE Framework

## Installation

1. Descargar la carpeta y extraer los archivos de ser necesario
2. Coloca la carpeta en `resources` preferiblemente en una carpeta destinada a scripts
4. Añade el ensure puctinov-handling-editor-for-qb en el archivo server.config 
5. Reinicia el servidor

##

En el config se puede ajustar los parametros que se permiten modificar además de los jobs que pueden hacerlo
